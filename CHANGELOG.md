# Changes

## 1.0

The first release.

- A menu bar remote for Apple TV: clickpad, Back, TV, Play/Pause, volume, 10-second skip and power.
- Arrow keys, Return, Esc and Space drive the TV while the remote has the keyboard.
- Pin the remote to make it a small floating window.
- Control-Option-R opens it from any app. The shortcut can be changed.
- Up to six favorite apps as one-click buttons.
- A line showing what is playing.
- Type on the Mac when the Apple TV asks for text.

Needs macOS 14 or later on Apple silicon. The app is not notarized, so the first open takes one extra step. `Read Me First.txt` in the zip walks through it.
